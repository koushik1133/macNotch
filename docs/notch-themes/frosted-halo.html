What you are seeing

  1. 1Frosted ring. Wallpaper blurred heavily (σ 9) and slightly saturated, only inside the halo band.
  2. 2White 12% fill. Lifts the frost so it reads as a light surface on dark and bright wallpapers alike.
  3. 3Grain. Fine noise at 8% so the frost looks like etched glass instead of a flat gradient.
  4. 4Hairlines. Outer hairline at 55% white and a fainter inner one where the ring meets the black body.
  5. 5Top light. The halo is a little brighter near the menu bar and fades toward the bottom edge.
  6. 6Bloom pulse. On hover entry a single thin light ring expands about 30 pt outward and fades in 0.7 s.

How SparkV will build it

The cheapest of the glass themes. It is mostly system materials.

Technique

A HaloRing(width:) shape (body outline grown by the halo width, minus the body) sits behind the black island. Its width animates from 0 to 15 pt. The frost comes from the window server, so SparkV does almost no drawing.

  • Frost, macOS 14 and 15: NSVisualEffectView with material .hudWindow, blending .behindWindow, state .active, masked with maskImage or a SwiftUI .mask(HaloRing).
  • Frost, macOS 26: .glassEffect(.regular.tint(.white.opacity(0.12)), in: HaloRing(width: 15)).
  • Fill and lines: .overlay(HaloRing().fill(.white.opacity(0.12))) plus a 0.5 pt strokeBorder at 55% white.
  • Grain: a 64 px noise tile at 8% opacity, or a one-line .colorEffect noise shader on macOS 14+.
  • Bloom: halo width on .spring(response: 0.5, dampingFraction: 0.82). The one-shot light ring uses keyframeAnimator (scale 1 → 1.25, opacity 0.5 → 0).
HaloRing(width: hovered ? 15 : 0)
  .fill(.clear)
  .background {
    if reduceTransparency {
      HaloRing(width: 15).fill(Color(white: 0.23))        // solid, no blur
    } else {
      BehindWindowBlur(.hudWindow).mask(HaloRing(width: hovered ? 15 : 0))
    }
  }
  .overlay(HaloRing(width: hovered ? 15 : 0).fill(.white.opacity(0.12)))
  .overlay(HaloRing(width: hovered ? 15 : 0).stroke(.white.opacity(0.55), lineWidth: 0.5))
  .keyframeAnimator(initialValue: Pulse(), trigger: hovered && !reduceMotion) { ring, p in
    ring.overlay(NotchOutline(inset: 15).stroke(.white.opacity(p.alpha), lineWidth: 1.5)
                   .scaleEffect(p.scale, anchor: .top))
  } keyframes: { _ in
    KeyframeTrack(\.scale) { CubicKeyframe(1.25, duration: 0.7) }
    KeyframeTrack(\.alpha) { CubicKeyframe(0, duration: 0.7) }
  }
  .animation(reduceMotion ? .easeOut(duration: 0.15)
                          : .spring(response: 0.5, dampingFraction: 0.82), value: hovered)

Cost

Target budget on Apple silicon. Every layer of this theme is removed from the view tree while the island rests, so the resting cost is zero.

Resting0%The halo view is removed when width is 0.
Hovered< 1% GPUThe blur is composited by WindowServer. SparkV only redraws during the 0.5 s bloom.
BatteryNegligibleStatic after the bloom: no timeline, no shader.

Accessibility

Reduce Motion: no bloom and no pulse. The halo cross-fades in at full width over 150 ms.
Reduce Transparency: the frost is replaced by a solid #3A3A40 ring with the same hairline, so the hover is still clear without any see-through layer.
Increase Contrast: the outer hairline becomes 1 pt solid white.
