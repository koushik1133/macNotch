Neon Tube

A red neon tube bent around the notch. It strikes like a real sign when your pointer arrives, three quick flickers and then steady light, hums quietly, and throws red light onto the wallpaper below.

How SparkV will build it

Native layers, not a web view.

Technique

Neon is a stack of strokes on the same outline: two pre-blurred red glows, a 3 pt red tube and a 1.1 pt pink-white core, grouped with .compositingGroup() so the flicker fades them as one lamp. The strike is a keyframeAnimator opacity track, seven keyframes over 1.1 s. Light on the wallpaper is a radial red layer inside SparkV's transparent panel, blended with .blendMode(.plusLighter).

The idle hum is an optional Metal shader through .colorEffect (macOS 14+). On macOS 13 it falls back to a CAKeyframeAnimation on the glow layer's opacity. Either way it stops after 8 s, and immediately in Low Power Mode.

// Four stacked strokes of one outline + a light spill (macOS 14+)
ZStack {
    spill.blendMode(.plusLighter)                     // red light below the notch
    IslandShape(metrics: m).fill(.black)
    Group {
        outline.stroke(red, lineWidth: 12).blur(radius: 16).opacity(0.6)
        outline.stroke(red, lineWidth: 6).blur(radius: 6)
        outline.stroke(red, lineWidth: 3)              // the tube
        outline.stroke(neonCore, lineWidth: 1.1)       // pink-white core
    }
    .compositingGroup()
    .keyframeAnimator(initialValue: 0.0, trigger: hovering) { lamp, lit in
        lamp.opacity(hovering ? lit : 0)
    } keyframes: { _ in
        KeyframeTrack {                                // strike, 1.1 s
            LinearKeyframe(0.85, duration: 0.055); LinearKeyframe(0.08, duration: 0.033)
            LinearKeyframe(0.90, duration: 0.066); LinearKeyframe(0.05, duration: 0.033)
            LinearKeyframe(1.00, duration: 0.099); LinearKeyframe(0.40, duration: 0.033)
            LinearKeyframe(1.00, duration: 0.077)
        }
    }
    .colorEffect(ShaderLibrary.neonHum(.float(t)))     // optional hum, 30 fps, 8 s max
}

Cost and accessibility

GPU and battery
The strike is 1.1 s of opacity. Glows are rasterised once per size, so a steady tube costs nothing. The hum is the only continuous work (about 1 % GPU at 30 fps), capped at 8 s and off when isLowPowerModeEnabled.
Reduce Motion
No flicker and no hum: the tube fades on in 200 ms and stays steady. The strike is three flashes on a 3 pt line, far under the WCAG 2.3.1 small-area limit, but Reduce Motion removes it entirely.
Reduce Transparency
No light spill and no blurred glows; only the solid tube and its core, at full contrast.
macOS support
macOS 14 for keyframeAnimator and colorEffect; macOS 13 uses CAKeyframeAnimation. Pure black body and no .glassEffect, so macOS 26 is identical.
