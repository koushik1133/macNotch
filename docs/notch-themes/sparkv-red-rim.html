SparkV Red Rim

The house style. A crisp line of signal red, the same #F01822 as sparkv.si, traces the notch outline the moment your pointer arrives, backed by a soft red glow. One short animation, then it holds perfectly still.

How SparkV will build it

Native layers, not a web view.

Technique

The island is one custom SwiftUI Shape, IslandShape, whose animatableData carries width, height, bottom radius and shoulder radius. The same outline drives the black body, the rim and the glow, so all three ride the open spring together.

The rim is two mirrored half-outlines with .trim(from: 0, to: progress): that is why the light starts at the bottom centre and climbs both sides into the menu bar. In SparkV's AppKit panel the same idea is a CAShapeLayer with a strokeEnd animation, and the glow layer has shadowPath set, so Core Animation never derives the shadow from pixels.

// IslandShape: flared shoulders, rounded bottom. animatableData = (w, h, rb, s)
IslandShape(metrics: m)
    .fill(.black)
    .background {                          // soft red bloom, rendered once
        IslandOutline(metrics: m)
            .stroke(Color.sparkRed, lineWidth: 16)
            .blur(radius: 16)
            .opacity(reduceTransparency ? 0 : (hovering ? 0.62 : 0))
            .drawingGroup()
    }
    .overlay {                             // rim light from the bottom centre
        ForEach(IslandHalf.allCases) { half in
            IslandHalfOutline(half, metrics: m)
                .trim(from: 0, to: hovering ? 1 : 0)
                .stroke(rimGradient, lineWidth: 1.6)
        }
    }
    .animation(reduceMotion
        ? .easeOut(duration: 0.15)
        : .timingCurve(0.25, 0.8, 0.25, 1, duration: 0.46), value: hovering)

Cost and accessibility

GPU and battery
One 460 ms animation when the pointer arrives, then zero redraws while it rests. The glow is rasterised once per size change and only its opacity moves. Budget: under 1 % GPU during the trace, 0 % idle.
Reduce Motion
Reads accessibilityReduceMotion: no trace. The full rim and glow crossfade in over 150 ms, and the open spring becomes a plain fade.
Reduce Transparency
The blurred bloom is dropped. The rim and a tight halo stay at full opacity, so the highlight is still clear on any wallpaper.
macOS support
macOS 13+ (Shape, trim, drawingGroup). On macOS 26 this theme deliberately skips .glassEffect: the body must stay pure black to match the camera housing.
