Breathing Pulse

The notch gets a heartbeat. On hover, a red ring and then a white ring ripple outward from the edge in a lub-dub rhythm while a soft glow swells and settles behind the island.

Hover: heartbeat, 2.4 sIdle cost: 0 framesWallpaper: Night BokehMin macOS: 14 (13 via Core Animation)

How SparkV will build it

Native layers, not a web view.

Technique

Rings are stroked copies of IslandOutline scaled from the top anchor, so they stay attached to the screen edge and grow outward around the shoulders and bottom corners. The second ring starts 0.26 s after the first: lub, dub.

The glow is never re-blurred: one blurred stroke is rendered per size and only its opacity animates. For shipping, the same timeline moves to Core Animation (CAShapeLayer rings in a CAAnimationGroup of scale and opacity, the second with a beginTime offset), so the render server plays it without waking SparkV's main thread.

// macOS 14+: one KeyframeAnimator drives the heartbeat while hovering
IslandShape(metrics: m)
    .fill(.black)
    .background {
        if hovering && !reduceMotion && !isOpen {
            KeyframeAnimator(initialValue: Beat(), repeating: true) { b in
                ZStack {
                    glow.opacity(b.breath)                 // pre-blurred, cached
                    IslandOutline(metrics: m)
                        .stroke(Color.sparkRed, lineWidth: 1.5)
                        .scaleEffect(x: b.lub.sx, y: b.lub.sy, anchor: .top)
                        .opacity(b.lub.alpha)
                    IslandOutline(metrics: m)
                        .stroke(Color.sparkPaper, lineWidth: 1.5)
                        .scaleEffect(x: b.dub.sx, y: b.dub.sy, anchor: .top)
                        .opacity(b.dub.alpha)
                }
            } keyframes: { _ in Beat.track(period: 2.4, dubDelay: 0.26) }
        } else if hovering {
            glow.opacity(isOpen ? 0.4 : 0.6)               // calm states
        }
    }

Cost and accessibility

GPU and battery
Only while the pointer is on the closed notch: two thin layers and one cached glow on a 2.4 s loop, about 1 % GPU. Rings stop as soon as the drawer opens; the 4.8 s breath that remains is a single opacity animation. Zero at rest.
Reduce Motion
No rings and no breathing. Hovering fades in one steady soft glow and a red rim; nothing scales or repeats.
Reduce Transparency
The blurred glow is removed; rings and rim stay as solid strokes at fixed opacity.
macOS support
KeyframeAnimator needs macOS 14; on macOS 13 SparkV uses the Core Animation path directly. Not tied to .glassEffect, so macOS 26 is identical.
