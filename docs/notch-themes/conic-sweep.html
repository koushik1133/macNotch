Conic Sweep

A border that moves. A conic gradient running red to white to red orbits the island outline while you hover, like light chasing around the rim of a lens, with a soft halo following it.

Hover: conic orbit, highlight every 2.8 sIdle cost: 0 framesWallpaper: Ink WavesMin macOS: 13

How SparkV will build it

Native layers, not a web view.

Technique

Quickest SwiftUI version: IslandShape().stroke(AngularGradient(stops:center:angle:), lineWidth: 2) inside a TimelineView(.animation(minimumInterval: 1/30, paused: !hovering)), with a blurred copy behind the body for the halo. It works, but re-evaluates the view on every frame.

SparkV ships the Core Animation version: a square CAGradientLayer of type .conic, larger than the island so it covers the outline at every angle, masked by a CAShapeLayer stroke of the outline and rotated by a repeating CABasicAnimation. The rotation runs in the window server, so SparkV's process does no per-frame work; only the mask path is swapped during the open spring.

// AppKit: the spin runs in the render server, SparkV's process stays idle
let sweep = CAGradientLayer()
sweep.type = .conic
sweep.colors = [red, paper, red, deepRed, red, paper, red, deepRed, red].map(\.cgColor)
sweep.locations = [0, 0.17, 0.34, 0.42, 0.5, 0.67, 0.84, 0.92, 1]   // two highlights
sweep.startPoint = CGPoint(x: 0.5, y: 0.5)        // conic centre
sweep.endPoint   = CGPoint(x: 0.5, y: 0)
sweep.frame = squareCovering(islandBounds)        // covers every angle

let ring = CAShapeLayer()                         // mask = 2 pt outline
ring.path = islandOutline(for: metrics)
ring.lineWidth = 2; ring.fillColor = nil; ring.strokeColor = .white
borderHost.mask = ring
borderHost.addSublayer(sweep)

let spin = CABasicAnimation(keyPath: "transform.rotation.z")
spin.byValue = 2 * Double.pi; spin.duration = 5.6; spin.repeatCount = .infinity
spin.preferredFrameRateRange = CAFrameRateRange(minimum: 24, maximum: 30, preferred: 30)
if !NSWorkspace.shared.accessibilityDisplayShouldReduceMotion {
    sweep.add(spin, forKey: "sweep")              // removed again on mouse exit
}

Cost and accessibility

GPU and battery
Continuous only while hovered or open: one ~620 × 200 pt layer recomposited per frame, capped at 30 fps on ProMotion. About 1–2 % GPU while visible. The animation is removed, not paused, at rest, so idle cost is zero.
Reduce Motion
The spin is never added. The gradient is frozen with its white highlight at the bottom centre, so the border still reads as lit.
Reduce Transparency
The blurred halo layer is dropped; only the crisp 2 pt gradient border remains.
macOS support
macOS 13+ (CAGradientLayer .conic, AngularGradient). No dependency on .glassEffect, so macOS 26 looks identical.
