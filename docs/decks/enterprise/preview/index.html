Speaker notes

This slide is the security reviewer's summary. Default: on-device Apple Intelligence; AI cost to us is $0, so there is no reason to route data to a server. Groq is optional, per feature, and uses the customer's own key; nothing uses it unless turned on. Licensing talks to Lemon Squeezy, the merchant of record. Face Unlock is excluded from the sold build because its face model is licensed for non-commercial use only. Gap to disclose: there is no admin-enforced switch to block Groq org-wide yet [TBD: managed preference to disable Groq].
